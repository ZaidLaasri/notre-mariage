# Design system

Ivoire #f8f6f1, papier #ffffff, sauge #526c5a, sauge pâle #e8eee7, camel #b99b78, rose #f3e6e2, texte #29372f. Titres serif système, texte sans-serif système ; aucune police ou API payante.

Sidebar desktop, navigation compacte mobile, largeur de lecture limitée. Cartes arrondies, bordures douces, grandes photographies, espaces généreux. Actions principales vert sauge, secondaires bordées. Labels persistants, focus visible, boutons natifs, contrastes lisibles. Réduction des animations selon préférence système.

Tableaux pour finances, cartes pour recherche visuelle, comparaison mobile empilée. États vides avec action, bannière démo permanente, messages d'erreur annoncés via aria-live. Les images décoratives ont un texte alternatif vide ; les photos d'offres portent une légende.

Nouveaux parcours : grille/mosaïque de moodboards (3, 2 puis 1 colonne), import photo clairement visible, timeline verticale avec rail horaire compact sur mobile, états de chevauchement textuels. Glisser-déposer complété par des boutons de réordonnancement pour clavier et écran tactile. Le mode consultation allège les actions du programme. Les composants de galerie et leur lightbox avec gestion du focus sont partagés avec le trousseau.
